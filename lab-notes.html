Lab Notes

Motion recipes, not decoration.

The best pages feel expensive because the animation has timing, hierarchy, and restraint. These are the patterns used across the project.

Recipes.

GSAP

Page wipe

Animate a fixed layer over the viewport before navigation so every page change feels intentional.

to(wipe, { yPercent: 0, ease: "expo.inOut" })
ScrollTrigger

Pinned runway

Use one tall section to control a horizontal track. The user scrolls vertically, the scene travels sideways.

to(track, { x: -distance, scrub: 0.85 })
Images

Mask reveal

Reveal photos with clip-path instead of only fading. It feels more like direction and less like a template.

from(card, { clipPath: "inset(35% round 20px)" })
Performance

Contain heavy sections

Big scenes stay smooth when images are lazy, canvases have a job, and off-screen work is reduced.

loading="lazy" + scrub only where needed
Interaction

Filter board

Filtering does not need a framework. A small GSAP state change gives the board tactile feedback.

to(card, { autoAlpha, scale, filter })
Direction

Land the beat

Every section should end with a readable resting state. Motion should guide the eye, then get out of the way.

reveal -> hold -> accelerate -> land
